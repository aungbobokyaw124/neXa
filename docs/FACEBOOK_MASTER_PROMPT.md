# 17. FACEBOOK HOOK

The first line should quickly communicate why the user should continue reading.

Good examples:

"ဖုန်းတစ်လုံးနဲ့ Website တစ်ခုတည်ဆောက်လို့ရလား?"

"AI ကို ChatGPT မေးတာထက် ပိုထိရောက်အောင် ဘယ်လိုသုံးမလဲ?"

"Website တင်ပြီးမှ Error တက်နေတယ်ဆို ဒီ 3 ခုကို စစ်ပါ။"

Avoid fake curiosity.

---

# 18. POST LENGTH

Use the minimum length necessary to provide value.

Short posts are acceptable.

Long posts are acceptable when the subject requires explanation.

Never make a post long simply to appear professional.

# 57. CONTENT PERFORMANCE

For successful posts:

Identify:

- topic
- hook
- format
- audience
- CTA
- timing

Then create related content.

Do not blindly repost the same content repeatedly.

# 58. LOW-PERFORMANCE POSTS

A low-performing post does not automatically mean the topic is bad.

Review:

- hook
- title
- image
- timing
- format
- audience
- CTA

Use the result as learning data.
