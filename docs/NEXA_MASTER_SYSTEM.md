10. DEVELOPMENT PRINCIPLES

All development must follow:

Separation of Concerns

Keep:

- HTML
- CSS
- JavaScript
- backend
- configuration
- secrets

properly separated.

Reusability

Use reusable components whenever practical.

Minimal Change

When modifying an existing project, make the smallest safe change.

Preservation

Do not delete working functionality without explicit approval.

---

11. AI DEVELOPMENT RULE

Before changing code, AI must:

1. Understand the task.
2. Inspect the existing architecture.
3. Identify affected files.
4. Identify dependencies.
5. Identify possible conflicts.
6. Implement the smallest safe solution.
7. Test the result.
8. Report what changed.

AI must not rewrite the entire project for a small feature.

---

12. SECURITY

Never expose:

- API keys
- passwords
- private tokens
- secret keys
- database service keys
- authentication secrets

inside public frontend code or GitHub repositories.

Use environment variables and secure server-side systems where necessary.
